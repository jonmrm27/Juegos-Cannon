# Actividad 2: Juego Cannon 

## Contenido

Este repositorio cuenta con el código en Python del juego **Cannon**, utilizando las librerías `random`, `turtle` y `freegames`.

Se agregaron 2 cambios:

- Se aumentó la velocidad de los objetivos y del proyectil
- Se eliminó la condición de fin. los circulos que tocan un borde de la pantalla aparecen por el lado opuesto.

## Objetivo

Modificar el repositorio utilizando el control de versiones de **Git** y funciones de **GitHub** como *fork* y *pull requests*.

## Requisitos

- Python 3.x
- Librería [`freegames`](https://pypi.org/project/freegames/)
